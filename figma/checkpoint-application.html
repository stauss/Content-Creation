Phase 01
01

Save points for design work.

A Figma plugin that lets you capture meaningful moments directly on the canvas. Select a frame. Create a checkpoint. Done.

Think version control — but visual, and built for how designers actually think. Each checkpoint stores a thumbnail, the full state, and context. Navigate, compare, and restore without leaving your file.

Create
One shortcut.
Select any frame or node and save that exact moment. No context switching, no new habit.
Preview
See the story.
Thumbnails, timestamps, groups — a clear visual record of how the design evolved.
Restore
Go back safely.
Navigate, compare, delete, or restore any checkpoint. Confident and predictable every time.

The moment a design starts to matter, it’s worth saving without having to think about it.

Why it works immediately

  • Solves a personal pain before it becomes a publishing problem
  • Stays inside Figma — where the work already lives
  • Storage stays lightweight; reverting is safe and predictable
  • No project setup, team account, or publishing workflow required
Phase 02
02

Process is the portfolio.

Once you're capturing meaningful moments, those moments become the raw material for work you're proud to show — without starting from a blank page.

No reconstruction. No backfilling. No recreating a story you already lived. Select the checkpoints that tell it best, add a line of context, and Checkpoint assembles the case study.

Built from real work. Not remembered after the fact.
  • Select and reorder checkpoints into a narrative arc
  • Add captions — decisions, pivots, what changed and why
  • Generate clean, shareable project pages and designer profiles
  • Keep private, messy, or confidential work hidden by default
  • Publish a link without rebuilding anything from scratch
